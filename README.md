# DDoS防护服务器：看懂防御数值、黑洞和清洗链路，按业务挑对机房不花冤枉钱

会去搜这个词的人，通常处在两种状态之一：业务已经被人打了，正在满世界找一台能顶住的机器；或者知道自己做的东西容易招打，想在上线之前把防护这件事买对。两种情况下的判断逻辑差别很大，但掉进去的坑往往是同一个——只看“防多少 G”这一个数字就下单。

## 先把攻击分成两类，否则钱一定花错

DDoS 是个统称，落到你服务器的监控面板上，表现完全不是一回事。

一类是打带宽的。SYN Flood、UDP Flood、各种反射放大攻击都属于这种，特征很直白：入方向流量瞬间飙满，机房出口被占死，正常用户根本挤不进来。这种攻击能不能扛住，取决于机房有没有清洗能力，跟你买几核 CPU 基本没关系。

另一类是打应用层的。CC 攻击是典型代表：请求数不算夸张，总流量也不大，但每个请求都要查一次数据库、走一遍登录逻辑，最后 CPU 和数据库连接数被打爆。这种攻击靠“防护带宽”是防不住的，需要的是频率限制、人机校验、URL 级别的规则过滤。

判断方法很土但有效——被打的时候先看监控，是带宽跑满还是 CPU 跑满。带宽跑满，往流量清洗方向找方案；CPU 跑满、连接数爆表，说明你缺的是 CC 防护，而不是一个更大的防御峰值。

## 防御数值不等于防护能力：清洗和黑洞是两回事

一套完整的 DDoS 防护大致走四步：检测到异常流量，通过 BGP 宣告把目标 IP 的流量牵引到清洗中心，过滤掉恶意包，再把干净流量回注给源站。整个过程对访客透明，理想情况下用户感知不到正在被打。

问题出在“峰值”这个词上。标称 100Gbps 防御，通常指的是清洗集群能处理的攻击流量上限，但超过阈值之后怎么办，各家差别很大：

- **真清洗**：超过阈值继续清洗或限速，业务还能维持，可能只是变慢。
- **直接黑洞**：把被攻击的 IP 整个从路由上撤掉。攻击流量确实进不来了，但正常用户也一起进不来，业务等于完全中断，解除时间从十几分钟到几小时不等。

低价高防最常见的做法就是后者——机房先保整体网络，牺牲你一台机器。所以采购前值得问清楚四个问题：持续清洗能力是多少、CC 这类应用层攻击怎么处理、误封了多久能恢复、黑洞的触发条件和解除流程是什么。能答清楚这些的服务商，比只会说“我们防护很强”的靠谱得多。

还有一条容易被忽略：既然防护有上限，那源站 IP 就别暴露。一旦攻击者拿到你的真实 IP，绕过任何高防产品直接打源站，前面花的钱全白费。

## 高防服务器、高防 IP、高防 CDN：三条不同的路

| 方案 | 是否要迁移业务 | 适合的业务形态 | 主要代价 |
| --- | --- | --- | --- |
| 高防服务器 | 要，整机迁到高防机房 | 游戏服务端、长连接业务、自定义 UDP/TCP 端口的服务 | 单价高于普通云服务器；IP 直接暴露，被持续打时防护上限就是买的那一档 |
| 高防 IP | 不用，改解析或改设备连接地址即可 | Web 站点、API、小程序后端、需要隐藏源站的业务 | 流量多绕一跳，有一定延迟；超大流量档位价格不低 |
| 高防 CDN | 不用，改域名解析 | 官网、H5 页面、静态内容为主的站点 | 只吃 HTTP/HTTPS，撑不了自定义端口的 TCP/UDP 长连接 |

这张表基本能解决大部分选择困难。如果你跑的是游戏服、语音服、物联网设备通信这类需要自定义端口或长连接的场景，高防 CDN 帮不上忙，得直接选带防御的机房机器；如果是普通网站，迁移成本高，优先考虑高防 IP 或 CDN；如果两样都怕，就上“CDN + 后端高防机房”的双层结构，成本也最高。

## 国内高防机房的实际价格区间

国内带防御的机房，价格结构其实很简单：你付的钱大部分买的是“清洗带宽”和“高防 IP”，硬件配置反而是次要变量。同样两台配置相近的机器，带 100G 防御的那台月租能高出一截，溢价几乎全部来自清洗资源。

所以选择时真正的成本项通常有三个：机器本身的月租、高防 IP 的加购费、以及流量超出后的费用。第三项最容易被低估——如果机房按流量计费又不管你，被恶意刷流量刷出欠费单的事每年都在发生。

## 买之前值得做的三件事

**第一，确认你要防的端口。** 很多低价高防只保护 80/443，一旦你的业务跑在自定义 TCP 端口或 UDP 上，防护等于没买。高防服务器和独立高防 IP 在这件事上的支持度明显好于纯 Web 防护产品。

**第二，把源站藏好。** 用了高防 IP 或 CDN，就把源服务器限制成只允许回源 IP 段访问，别让历史 DNS 记录、邮件服务、外链资源把真实 IP 漏出去。

**第三，用试用期做验证。** 雨云这类支持 1 元试用 1 天、7 天无理由退款的模式，适合先跑通业务再决定要不要年付——毕竟防护到底能不能扛住、清洗后延迟涨多少，只有真接了才知道。

## 常见问题

**100G 防御够用吗？**
对绝大多数中小型网站、游戏服和 API 服务，100G 已经覆盖了常见的商业竞争级攻击。真正需要担心的不是峰值数字，而是超过阈值后是被清洗还是被黑洞——这一点要提前问清楚。如果你的业务属于高频被针对的行业（游戏、金融、区块链、直播），预算允许就往更高防御档位走，或者做双层结构。

**带防御的服务器能防 CC 吗？**
只能部分解决。机房侧的清洗主要针对流量型和协议型攻击，应用层的 CC 依赖频率限制、人机校验这类策略。买之前确认服务商有没有配套的防火墙规则或 WAF 能力，比单纯堆防御带宽有用。

**NAT 机和独立 IP 怎么选？**
NAT 机型共享公网 IP，便宜，但只能开放有限端口，而且同 IP 上别人被打你也会跟着受影响，适合内网穿透、学习、开服测试。要做正经网站或者需要独享防御，选独立 IP。

**年付真的划算吗？**
年付 7 折是雨云的常规政策，如果叠加新用户首月 5 折券，总体支出能压下来一截。但前提是你已经用试用期验证过线路和防护表现，别为了折扣把一个还没跑通的方案锁一年。

回到最开始那个问题：DDoS 防护服务器怎么选，本质上是在“攻击会打到哪里”和“你能接受多久不可用”之间找一个价格合适的交点。想清楚这两件事，再看防御数值、清洗方式和加购价格，判断就不会太偏。
